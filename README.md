# سیستم منوی آنلاین رستوران و کافه

یک سامانه‌ی **مالتی‌تننت** (چند مجموعه‌ای) برای منوی آنلاین رستوران و کافه،
ساخته‌شده با **PHP + MySQL** و کاملاً سازگار با **هاست اشتراکی ایرانی** (cPanel / DirectAdmin / LiteSpeed).

> هر مجموعه (رستوران/کافه) یک «مستاجر» مستقل با قالب، رنگ‌بندی و منوی جداگانه است؛
> پس منوی دو مشتری هیچ‌وقت شبیه هم نمی‌شود.

## 🤖 ربات تلگرام و بله (کامل و آماده)

ربات واقعی با **وب‌هوک** پیاده‌سازی شده (بدون نیاز به long-polling، مناسب هاست اشتراکی):

1. در «اتصالات» توکن ربات (از BotFather تلگرام یا BotFather بله) را وارد و ذخیره کنید.
2. روی دکمه‌ی **«ثبت خودکار وب‌هوک روی ربات»** بزنید (دامنه باید **HTTPS** داشته باشد).
3. مشتری ربات را با `/start` باز می‌کند → ربات دکمه‌ی «ارسال شماره تماس» را نشان می‌دهد →
   با اشتراک شماره، `chat_id` به‌صورت خودکار به مشتری متصل می‌شود.
4. از این پس کمپین‌ها و تبریک تولد به‌صورت پیام مستقیم به ربات ارسال می‌شوند.

مسیر وب‌هوک: `POST /bot/{telegram|bale}/{tenant_id}/{secret}` — `secret` به‌ازای هر مجموعه
خودکار ساخته و فقط روی سرور نگه داشته می‌شود.

## 🔭 نقاط اتصال آماده (برای تکمیل در فاز بعد)

این بخش‌ها معماری و رابط آماده دارند و فقط باید اعتبارنامه‌ی واقعی و فراخوانی نهایی provider اضافه شود:

- **درگاه پرداخت ایرانی** — `app/Services/PaymentGateway.php` (اسکلت زرین‌پال/زیبال/IDPay)
- **حسابداری ایرانی** — `app/Services/AccountingService.php` (حسابفا/هلو/سپیدار) برای رتبه‌بندی بر اساس خرید واقعی
- **پیامک** — `app/Services/Messenger.php` (نمونه‌ی کاوه‌نگار آماده)

## 🚀 نصب روی هاست اشتراکی

1. همه‌ی فایل‌ها را آپلود کنید و **document root** دامنه را روی پوشه‌ی `public/` تنظیم کنید
   (اگر امکان تغییر docroot نیست، محتویات `public/` را در `public_html` بگذارید و یک پوشه بالاتر بقیه‌ی فایل‌ها را).
2. یک دیتابیس MySQL بسازید (از cPanel).
3. در مرورگر به `https://دامنه/install.php` بروید و فرم را پر کنید.
4. بعد از پیام موفقیت، **حتماً فایل `public/install.php` را حذف کنید**.
5. ورود به پنل: `https://دامنه/admin/login`
6. منوی عمومی: `https://دامنه/m/نامک-مجموعه`

### کرون تبریک تولد و رتبه‌بندی (روزانه)
در بخش Cron Jobs هاست اضافه کنید:
```
0 9 * * *  /usr/bin/php /home/USER/path/cron/daily.php >/dev/null 2>&1
```

> نکته: اگر در زیرپوشه نصب کردید، مقدار `app.base_path` را در `config/config.php` تنظیم کنید
> و در صورت نیاز `RewriteBase` را در `public/.htaccess`.

> **ارتقا از نصب قبلی:** اگر دیتابیس را قبل از افزوده‌شدن ربات ساخته‌اید،
> یک‌بار فایل `db/migrations/2026_06_add_bot_chat_ids.sql` را در phpMyAdmin اجرا کنید.

## 🗂️ ساختار پروژه

```
app/
  Core/         Database, Router, View, Auth, Upload, helpers
  Controllers/  PublicController + Admin/*
  Services/     Pricing, Ranking, Messenger, Integration,
                PaymentGateway, AccountingService, BirthdayService
  Views/        layouts/ public/ admin/ errors/
config/         config.example.php  (config.php پس از نصب ساخته می‌شود)
db/             schema.sql
public/         index.php (front controller), assets/, uploads/, install.php
cron/           daily.php
```

## 🧱 پشته فنی
- PHP 8.x (بدون نیاز به composer یا فریم‌ورک)
- MySQL / MariaDB (utf8mb4)
- بدون وابستگی build سمت کلاینت؛ فونت Vazirmatn از CDN

## 🔒 امنیت
- PDO + Prepared Statements (ضد SQL Injection)
- خروجی escape شده (`e()`)، توکن CSRF روی همه‌ی فرم‌ها
- آپلود امن تصویر (بررسی MIME، محدودیت حجم، نام تصادفی)
- گذرواژه با `password_hash` (bcrypt)، session سخت‌شده
